# Spring Framework Practice

This repository contains my hands-on practice while learning the Spring Framework.

I am learning Spring step by step by creating small examples and practicing core concepts.

## About This Repository

This project is created for learning and practicing Spring Framework concepts using Java, Maven, and Eclipse.

Topics are practiced through small code examples for better understanding.

## Topics Covered

  - Spring Framework Introduction
  - IoC (Inversion of Control)
  - Dependency Injection
  - Setter Injection
  - Constructor Injection
  - Bean Configuration using XML
  - p-schema configuration
  - Bean lifecycle
  - Autowiring
  - Collection Injection
  - Standalone Collections
  - Spring Expression Language (SpEL)
  - Bean Scope
  - Annotation-based configuration
  - Java-based configuration
  - Maven project setup
